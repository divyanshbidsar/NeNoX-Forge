Team Details & Open Roles

Detailed breakdown of specialized roles for our hackathon lineup

Ethical Hacker / Security Specialist

Tech Stack: Linux (Debian/Arch/RHEL), Bash/Shell scripting, Nmap, Metasploit, Wireshark, Burp Suite, Network Security, System Hardening.

You are the team's defensive shield and offensive strategist. Your job is to secure application endpoints, manage secure cloud/Linux deployments, and identify critical vulnerabilities before deployment. For cybersecurity-focused hackathon tracks, you lead exploit demonstrations, write custom penetration scripts, and ensure all API integrations adhere to strict zero-trust standards under intense time constraints.

Frontend Developer

Tech Stack: React.js, Next.js, TypeScript, Tailwind CSS, Redux/Zustand, WebSockets, Responsive UI Architecture.

You own the client-side execution and user experience. You convert raw Figma prototypes into production-ready, lightning-fast web applications. You are responsible for modular state management, seamless API integration, dynamic client-side rendering, and ensuring the final product looks polished, responsive, and ready for live judge demonstrations within hours.

Backend Developer

Tech Stack: Python (FastAPI/Django), Node.js (Express), RESTful & GraphQL APIs, PostgreSQL/MongoDB, Redis, LLM Integration, ML Pipelines.

You build the engine powering our applications. Your primary focus is designing scalable server architectures, optimizing database schema, managing authentication flows, and integrating AI models or external data pipelines. You work closely with the frontend team to supply clean endpoints and keep backend response times virtually instantaneous during live stress tests.

Research, Strategy & PM

Tech Stack: Market & Academic Research, Agile/Scrum Management, Problem Framing, Notion/Jira, Pitch Deck Strategy, Executive Storytelling.

You are the team’s operational backbone and product strategist. You validate problem statements, analyze target audience pain points, and define the core minimum viable product (MVP) scope so developers don't waste time on non-essential features. You maintain strict sprint timelines during 24–48 hour hackathons, manage documentation, and craft the winning narrative for final judge presentations.

UI/UX Designer & Product Lead

Tech Stack: Figma, Interactive Prototyping, Design Systems, Wireframing, User Flow Mapping, Pitch Deck Visuals, UI Motion/Animation.

You define how the product feels, functions, and presents to judges. You translate rough ideas into clean, intuitive wireframes and high-fidelity interactive prototypes. You establish the visual brand, design system, and color palette early in the sprint, ensuring the engineering team has clear UI guidelines. Additionally, you design high-impact pitch deck visuals that hook judges instantly.
