# Recent Updates

Add each entry as a `##` heading. Copy the relevant example to the end of this file and replace the sample text.

For an event, use `Type: Event`, `Date`, `Badge`, `Description`, and `Details`. Separate multiple detail items with `|`. `Link` and `Link label` are optional; links must use an `http` or `https` URL.

    ## Example: Build Weekend
    - **Type:** Event
    - **Date:** ONLINE - 12-13 DEC 2026
    - **Badge:** OPEN TO ALL
    - **Description:** A weekend event where participants collaborate to build and present a small project.
    - **Details:** TEAM: 1-4 | MODE: ONLINE
    - **Details:** REGISTRATION: OPEN
    - **Link:** https://example.com/register
    - **Link label:** Register now

For a policy or informational notice, use `Type: Policy`, `Label`, and `Description`:

    ## Example: Registration reminder
    - **Type:** Policy
    - **Label:** REMINDER
    - **Description:** Check the event page for eligibility and registration deadlines before applying.
